**Acadly** is a unified, role-based platform designed specifically for college activity management. Say goodbye to scattered WhatsApp groups, disorganized Google Calendars, and messy spreadsheets. Acadly brings your entire committee's workflow into one sleek, glassmorphic workspace.

## ✨ Why Acadly?

*   **Unified Workspace:** Manage calendars, tasks, and member submissions all from one centralized dashboard.
*   **Enterprise-Grade Access Control:** True server-enforced role hierarchies (Viewer ➔ Member ➔ Team Lead ➔ Core Organizer ➔ Owner) ensure the right people have the right access.
*   **Gamified Accountability:** A built-in, transactional points engine automatically tracks on-time, late, and missed task submissions to keep your team motivated.
*   **Beautifully Crafted Design:** A stunning, modern glassmorphism UI with full Light/Dark mode support that users love to interact with.

## 🛠️ Key Features

*   **🔒 Secure Onboarding:** Invite codes coupled with an admin approval queue keep your "Spaces" exclusive and private.
*   **✅ Smart Task Management:** Assign tasks, review submissions, and provide ratings or revision requests directly within the app.
*   **🔔 In-App Notifications:** Stay in the loop instantly on access requests, new tasks, and submission reviews.
*   **📜 Complete Audit Trails:** Full transparency for admin actions like approvals, role changes, and invite code regenerations.

---

### 💻 Tech Stack
*   **Frontend:** Next.js 14 (App Router) + TypeScript + Tailwind CSS
*   **Auth:** Auth.js (NextAuth) for secure JWT sessions
*   **Database:** PostgreSQL via Supabase, orchestrated by Prisma
